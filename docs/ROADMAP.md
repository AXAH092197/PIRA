# PIRA Rebuild Roadmap

## Phase 0: Discovery
- [ ] Obtain original application source and audit dependencies.
- [ ] Confirm stack, hosting, and database.
- [ ] Trace requirements to tests.

## Phase 1: Secure foundation
- [ ] Define account, workspace, membership, role, session, inventory, and audit models.
- [ ] Implement verified email, MFA, session lifecycle, and authorization.
- [ ] Test cross-workspace isolation and permission denial.

## Phase 2: Core application
- [ ] Inventory CRUD, tags, search, sorting, and reminders.
- [ ] Accessible responsive dashboard and settings.
- [ ] Personal/business workspace switching and isolated-session option.

## Phase 3: Extended functionality
- [ ] Bulk import, reporting, sharing, and plan entitlements.
- [ ] Restricted administration and programmer console.
- [ ] Evaluate billing and optional AI features after privacy/security review.

## Phase 4: Release
- [ ] Accessibility, security, privacy, backup/recovery, and deployment verification.
- [ ] Rollback and release documentation.
