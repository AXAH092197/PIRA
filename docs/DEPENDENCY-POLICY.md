# Dependency Policy

No runtime dependencies have been selected or installed yet.

Every proposed package must document: purpose, owner/maintainer, license, version, transitive dependencies, security history, maintenance cadence, privacy/network behavior, alternatives, and reason native platform functionality is insufficient.

Avoid unnecessary analytics, tracking, AI SDKs, authentication plugins, and UI frameworks. Do not introduce payment processors or messaging providers until product requirements and data-handling terms are approved.

Pin versions with lockfiles, use automated vulnerability checks, review updates, and remove unused packages. Never install or execute unknown repository scripts during audit without inspection.
